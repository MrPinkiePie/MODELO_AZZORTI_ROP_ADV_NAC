# data

- **cargar_datos.py** — carga las tablas 1.1 (destino/origen), 1.2 (factor regional advance), VEH_EST, inflados/COD_INF, CON_PRD y la tabla de competidores.
- **cargar_datos_raw.py** — no implementado (ver docstring).
- **limpiar_datos.py** — cruce con vehiculo/estrategia, marcado de atipicos/faltantes, filtros de rango y de negocio (SURT/SORPRESA).
- **mis_funciones.py** — utilidades compartidas (manejo de campanas, metricas, logging).
